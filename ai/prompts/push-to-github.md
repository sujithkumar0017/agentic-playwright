# Push to GitHub Prompt

You have completed the code changes and they have been reviewed.

Now push the changes to the GitHub repository.

### Steps to Perform
1. Check git status
2. Stage all relevant changes (`git add .`)
3. Create a meaningful commit message based on the changes made
4. Commit the changes
5. Push to the current branch (or main/master)

### Rules
- Do not force push
- Do not push if there are uncommitted secrets or sensitive files
- Show the commit message before pushing
- Confirm the push was successful
